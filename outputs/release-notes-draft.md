# Preliminary Release Notes for PaperLike

## Highlights
PaperLike is a free, local-first EPUB reader that imports EPUB copies into a local library without moving the originals. Key features include:
* Chapter navigation
* Saved chapter and scroll position
* Customizable text size
* Three themes: Paper, Ivory, and Night

## Known Limitations
The following features are not yet implemented:
* Book images
* Rich inline EPUB styling
* Bookmarks
* Search
* PDF support
* Syncing

Additionally, the Windows x64 build is a preview and has not been verified on a Windows machine. macOS packages are ad-hoc signed and not notarized.

## Availability
Please note that this is a preliminary draft and not a published release. The license is undecided, and no public release is confirmed.
