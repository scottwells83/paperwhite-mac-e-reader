# Preliminary Release Notes for PaperLike

## Highlights

* Local-first EPUB reader for Windows and macOS
* Import EPUB copies into a local library without moving the originals
* Supports chapter navigation and saves chapter and scroll position
* Offers customizable themes (Paper, Ivory, Night) and adjustable text size
* Keeps books and progress on the computer without accounts or cloud upload

## Known Limitations

* Book images and rich inline EPUB styling are not shown
* Bookmarks, search, PDF support, and syncing are not included
* The Windows x64 build is a preview and has not been launched on macOS
* macOS packages are ad-hoc signed and not notarized

## Availability

This is a preliminary draft and not a published release. The software is not yet released, and the license has not been decided. Please note that the Windows x64 build is a preview and not fully tested on macOS.
