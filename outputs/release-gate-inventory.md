# PaperLike Release Readiness Inventory

## Confirmed capabilities and status

- EPUB imports are copied into the library; originals stay in place.
- Readers can browse chapter headings and reopen at a saved chapter and scroll position.
- Paper, Ivory, and Night themes and adjustable text size are supported.
- The library and reading progress are stored locally.
- macOS packaging, local installation, sample EPUB import, theme switching, and chapter resume were reviewed on macOS.
- The Windows x64 build has been cross-published but has not been tested on a Windows machine.
- macOS packages are ad-hoc signed and not notarized.

## Known product limitations

- Chapter text extraction does not show book images or rich inline EPUB styling.
- Bookmarks, search, PDF, and syncing are not included.

## Open release decisions

- Choose a source license.
- Confirm authorization for publication to the GitHub repository.
- Decide whether to obtain Developer ID signing and notarization for macOS distribution.

## Checks not yet performed

- Launch and review the Windows x64 application on a Windows machine.
